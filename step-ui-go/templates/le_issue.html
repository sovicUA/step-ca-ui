DNS-01 Cloudflare: Автоматично створює запис TXT через Cloudflare API. Налаштуйте API Token у налаштуваннях LE.

Як це працює

Let's Encrypt випускає безкоштовні сертифікати SSL для публічних доменів строком на 90 днів.

HTTP-01

Підходить, якщо сервер доступний з інтернету на порту 80.

DNS-01

Підходить для будь-яких доменів. Потребує доступу до DNS через API.

Автооновлення перевіряє сертифікати кожні 24 години й оновлює за 30 днів до кінця строку.
