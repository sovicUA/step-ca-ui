Резервна копія

Експорт критичних даних CA і Step-CA UI для ручного відновлення

Backup bundle

Архів містить manifest із контрольними сумами SHA-256, дамп PostgreSQL і архіви томів Docker, доступних контейнеру Step-CA UI.

PostgreSQLpostgres-stepui.sql
Step-CA datastep-ca-data.tgz з /home/step
Step-UI datastep-ui-data.tgz, step-ui-certs.tgz, step-ui-uploads.tgz
Manifestmanifest.json з версіями, розмірами й контрольними сумами
Важливо
  • Backup містить приватні ключі CA. Зберігайте архів як секрет.
  • Restore з UI навмисно не реалізовано: відновлення може перезаписати ключі CA і базу.
  • Перевірену ручну процедуру описано в BACKUP_RESTORE.md.
  • Перед оновленнями можна також використати CLI: sudo ./install.sh --mode backup --lang ru.
