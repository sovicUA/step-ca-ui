Інструкція: створення JWK-провізіонера на зовнішньому Step-CA

Step-CA UI взаємодіє зі Step-CA через JWK-провізіонер і випускає сертифікати строком дії до 10 років (87600h). На сервері зовнішнього CA виконайте:

1. Створення нового JWK-провізіонера з паролем і потрібними обмеженнями: 
step ca provisioner add admin \
  --type JWK \
  --create \
  --x509-default-dur 8760h \
  --x509-max-dur 87600h
CLI запитає пароль для шифрування ключа провізіонера. Якщо конфігурація не в типовому каталозі, вкажіть --ca-config /etc/step-ca/config/ca.json.
2. Якщо провізіонер уже існує, оновіть його claims: 
step ca provisioner update admin \
  --x509-default-dur 8760h \
  --x509-max-dur 87600h \
  --ca-config /etc/step-ca/config/ca.json
3. Перезапустіть службу step-ca: 
sudo systemctl restart step-ca

Після цього введіть ім’я провізіонера й заданий пароль у формі вище, завантажте сертифікати Root і Intermediate CA і натисніть «Зберегти налаштування».
